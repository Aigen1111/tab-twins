# Changelog

## 0.2.0 — 2026-10-22

### Added

- Firefox for Android support, with a touch-friendly layout. Window and tab-group filters are hidden where the browser doesn't have them.
- English interface. The language follows the browser (English by default, Spanish for Spanish browsers).
- Per-browser downloads: `tab-twins-<version>-chromium.zip` and `tab-twins-<version>-firefox.zip`, published automatically with each release.
- Privacy policy and MIT license.

### Changed

- The synopsis or series page of a novel is now grouped with its open chapters, so "Close duplicates" keeps only the chapter chosen by the rule.
- The window label is only shown when more than one window is open, and the tab-group filter only when there are tab groups.
- Final Firefox add-on ID: `tab-twins@needyfriends`.

## 0.1.0 — 2026-10-22

- First version for Chrome, Brave and Firefox: duplicate detection (identical and same work), search popup, manager with filters, side-by-side comparison, closing with confirmation and undo, badge with extra tabs.
